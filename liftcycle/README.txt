LIFTCYCLE - FREE IPHONE WORKOUT TRACKER

WHAT IT DOES
- Alternates Push and Pull after a completed session, not after a skipped day.
- Tracks exercises, weights, reps and dates.
- Graphs total bench press and deadlift volume per workout.
- Stores all data locally in your browser; export a JSON backup from Settings regularly.

HOW TO PUT IT ON YOUR IPHONE (FREE)
1. Create a free GitHub account at github.com, if needed.
2. Create a new public repository (for example, liftcycle).
3. Upload the CONTENTS of this liftcycle folder to the repository root:
   index.html, manifest.webmanifest, sw.js, and the three icon PNG files.
   (Do not upload the ZIP as a ZIP: extract it first.)
4. In repository Settings > Pages, under Build and deployment, choose
   Deploy from a branch > main > / (root) > Save.
5. Open the GitHub Pages website link that GitHub displays in Settings > Pages
   in Safari on your iPhone. The address usually has the format
   https://YOUR-USERNAME.github.io/liftcycle/
6. In Safari tap Share > Add to Home Screen > Add.
7. Use the new LiftCycle icon on your Home Screen.

IMPORTANT
- GitHub Pages can publicly serve the app code. Your personal workout logs
  are NOT uploaded to GitHub; they stay in your iPhone's browser storage.
- iPhone Home Screen web apps can use separate website storage from Safari.
  Use the Home Screen app consistently and make regular exports.
- Uninstalling the app or clearing website data may erase local workout logs.
- This prototype was created as source files; it has not been device-tested.
- Changing the app source requires uploading updated files and refreshing it.
